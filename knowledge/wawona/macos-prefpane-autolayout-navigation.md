# macOS PrefPane (retired)

Updated 2026-10-09. System Settings → Wawona PrefPane is **retired**.

Global Settings exclusivity: in-app Machines sidebar only
(`wawona-global-settings-exclusive`). Do not rebuild `Wawona.prefPane`,
`Settings.bundle`, or open `x-apple.systempreferences:…Wawona.prefPane`.

Install / pkg delete stale PreferencePanes copies. Env Vars editor is
in-app (`EnvironmentVariablesView`). Historical PrefPane Autolayout notes
live in git history around `8f2335a`.
